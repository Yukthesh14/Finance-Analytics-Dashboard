# Finance Analytics Dashboard

## Overview
This project is an interactive dashboard built using Google Looker Studio to analyze sales, profit, and cost data. The main idea was to understand how the business is performing across different countries,product categories, and time periods.

## Dashboard Link
You can view the dashboard here:  
(https://datastudio.google.com/s/rLqfmDCbVLU)

## What I Did
- Created an interactive dashboard to track sales, profit, and cost.
- Added filters to analyze data by region.
- Compared performance across countries and product categories.
- Visualized monthly sales trends and quarterly cost patterns.

## Key Metrics
- Sales: 55.4M  
- Profit: 31.6M  
- Cost: 23.8M  

## Key Insights
- The business is generating good profit compared to cost.
- The United States is the top contributor to profit.
- Categories like Computers and Cameras are performing better than others.
- Some categories are not contributing much and may need improvement.
- Sales show some variation across months, indicating possible seasonality.

## Tools Used
- Google Looker Studio
